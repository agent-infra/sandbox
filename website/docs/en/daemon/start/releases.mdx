## Prebuilt images

The images keep the AIO 1.x build with the Python server replaced by the daemon, and change some environment defaults and preinstalled packages. Image versions are independent of daemon versions. For Windows or anything else, build your own image from the binaries; see [Deployment & Operations](/daemon/ops/deployment).

- `enterprise-public-cn-beijing.cr.volces.com/vefaas-public/aio-daemon:1.0.1`
- `enterprise-public-cn-beijing.cr.volces.com/vefaas-public/aio-computer:1.0.1`

The run commands are in [Quick Start](/daemon/start/quick-start#from-a-prebuilt-image).
